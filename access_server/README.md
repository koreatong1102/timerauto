# 운영자용 온라인 승인 서버

## 현재 상태 / 반드시 먼저 읽기

**운영자 요청으로 현재 기능을 일시 중단했습니다.** `access_policy.py`의 `ONLINE_ACCESS_ENABLED = False` 상태에서는 승인 화면/인증 요청/실행 중 확인/서버 미설정 배포 제한 없이 기존처럼 실행됩니다. 코드와 기존 등록 데이터는 삭제하지 않았습니다. 재활성화하려면 아래 서버 설정을 먼저 완료한 뒤 이 값을 `True`로 바꾸고 다시 배포해야 합니다.

서버 코드는 **실제 Cloudflare 계정에 배포되지 않았고**, `AUTH_SERVER_URL`도 비어 있습니다. 인증을 다시 켠 상태에서는 서버 미설정 시 앱 실행/배포가 거부됩니다. 현재 켜져 있는 이전 앱을 강제 종료하거나 OBS를 변경하는 작업은 하지 않았습니다.

승인 서버/DB/관리자 페이지는 Cloudflare 계정 하나에 둡니다. 별도 도메인과 텔레그램은 필요 없습니다. 단, 서버 설정 자체는 처음 한 번 해야 합니다. 아래 `npx` 명령은 Node.js가 필요하고 최초 실행 시 Cloudflare의 Wrangler 도구를 내려받을 수 있습니다. 관리자/Cloudflare 로그인은 운영자가 직접 합니다.

## 처음 한 번 설치

PowerShell에서 프로젝트의 `access_server` 폴더로 이동한 뒤 순서대로 실행합니다.

### 1. Cloudflare 로그인과 DB 생성

```powershell
npx wrangler login
npx wrangler d1 create timerauto-access
```

브라우저에서 자신의 Cloudflare 계정으로 로그인합니다. 생성 결과의 `database_id`를 `wrangler.jsonc`의 `REPLACE_WITH_YOUR_D1_DATABASE_ID` 자리에 넣습니다. DB ID는 비밀번호가 아닙니다. 생성 명령이 설정을 자동 변경했다면 `binding`이 `DB`인지와 데이터베이스 항목이 중복되지 않았는지 확인합니다. 다른 프로젝트 DB를 연결하지 마세요.

### 2. 새 DB에 테이블 만들기

```powershell
npx wrangler d1 migrations apply timerauto-access --remote
```

대상 DB 이름을 확인하고 진행합니다. 처음 만든 전용 DB에만 적용하세요.

### 3. 운영자 비밀번호 등록

비밀번호 관리자에서 **32자 이상의 무작위 비밀번호**를 생성하고 보관하세요. 그다음:

```powershell
npx wrangler secret put ADMIN_PASSWORD
```

입력 프롬프트에 붙여 넣습니다. 비밀번호를 명령줄 인수, 소스, `config.json`, GitHub, 채팅이나 진단 ZIP에 넣지 마세요. 사용자에게도 보내지 않습니다. 로그인은 8시간 유지되며 휴대폰 브라우저 비밀번호 관리자에 저장해도 됩니다. 관리자는 Cloudflare 계정에 2단계 인증을 설정하는 것이 좋습니다.

### 4. 서버 올리기

```powershell
npx wrangler deploy
```

출력된 `https://timerauto-access.본인계정.workers.dev` 주소를 보관합니다. 앱 인증 API는 Cloudflare Access 로그인으로 감싸지 마세요. API는 앱 고유 토큰으로 인증하고 관리자 페이지는 자체 운영자 로그인으로 보호합니다.

### 5. 앱에 주소 연결

프로젝트 상위 폴더의 `access_policy.py`에서 다음 값을 실제 HTTPS 주소로 바꿉니다. `/admin`을 붙이지 않습니다.

```python
AUTH_SERVER_URL = "https://timerauto-access.본인계정.workers.dev"
```

이는 공개 서버 주소이고 비밀키가 아닙니다. Python 실행과 EXE는 **같은 파일/정책**을 사용합니다. 임의의 사용자 설정으로 인증을 끄는 스위치는 없습니다. 기존 `배포하기.bat`로 앱 업데이트를 올리기 **전에** 운영자 PC에서도 신청→승인→실행→사용 중지→종료→재허용→재실행을 실제 확인하세요. 서버를 배포하는 것과 앱 업데이트 배포는 별개입니다. 서버 관리자 파일/비밀번호는 앱 패키지에 포함하지 않습니다.

### 6. 휴대폰에서 사용하기

휴대폰 브라우저로 `서버주소/admin`에 접속하고 비밀번호로 로그인합니다. 이 페이지를 즐겨찾기/홈 화면에 추가하세요.

- **승인 대기**: 사용자가 카톡으로 알려준 이름과 PC 등록번호를 대조하고 승인합니다. 표시 이름은 자기 신고이므로 이름만 믿고 승인하지 마세요.
- **전체 / 허용 / 중지**: 기존 사용자를 찾아 관리합니다.
- **승인 / 다시 허용**: 등록된 PC 사용을 허용합니다.
- **사용 중지**: 해당 등록의 권한을 회수합니다. 앱은 다음 확인 때 종료합니다.
- **PC 등록 초기화**: 현재 인증을 삭제하고 새 요청부터 다시 승인받게 합니다. 승인된 PC도 이 버튼을 누르면 다음 확인 때 종료합니다. 포맷 후 새 PC 등록번호가 생겼다면 이전 등록은 별도로 중지하세요.
- **목록 새로고침**: 새 신청을 확인합니다. 자동 카톡/휴대폰 푸시 알림은 없습니다.
- **로그아웃**: 해당 휴대폰 로그인 세션을 즉시 만료시킵니다.

관리자 비밀번호를 바꾸면 기존 관리자 로그인 세션도 사용할 수 없게 됩니다. 앱 사용자 승인은 유지됩니다.

## 동작과 한계

- 앱 실행 전에 온라인 승인이 필요합니다. 감지/OBS/자동화가 시작되기 전에 확인합니다.
- 실행 중 확인 간격 15초, 요청 제한시간 5초. 명시적 중지는 다음 확인에 바로 적용됩니다. 오류를 승인으로 처리하지 않습니다.
- 일시적인 서버/인터넷 오류는 마지막 성공 후 45초만 유예합니다. 진행 중인 요청 때문에 최대 약 5초가 추가될 수 있습니다. 서버가 고장 나면 승인된 사용자의 앱도 결국 종료됩니다. 이는 상시 온라인 제한의 의도적인 절충입니다. GUI 자체가 멈춘 경우 종료 신호 처리가 지연될 수 있어 '무조건 15초'를 보장하지 않습니다.
- 사용 중지는 이 앱을 종료하는 것입니다. OBS 방송/녹화 중지 명령, 원본 영상 삭제, 사용자 파일 삭제는 보내지 않습니다. 창을 숨기기만 해서 감지/자동화가 남도록 하지 않습니다.
- 재허용 후 앱을 재실행합니다. 중지된 앱이 자동으로 방송 기능을 다시 켜지는 않습니다.
- 사용자 토큰은 무작위 256비트, 서버에는 해시로 저장합니다. Windows DPAPI로 PC 사용자별 암호화하여 `%LOCALAPPDATA%/TimerAuto/access/`에 저장하고 프로젝트 설정/진단 ZIP과 분리합니다. OS 원본 PC 식별값 대신 SHA-256 해시만 전송합니다. 토큰을 잃었을 때 자동으로 새 토큰을 덮어써 차단을 우회하지 않습니다.
- 관리자 로그인은 Secure/HttpOnly/SameSite=Strict 쿠키, 8시간 만료, 같은 출처에서만 변경 허용, IP당 10분에 로그인 시도 5회 제한입니다. 관리 화면 사용자 이름은 HTML이 아닌 텍스트로 표시합니다. DB 입력은 바인딩합니다. 오래된 세션/제한 카운터는 일일 정리합니다.
- 하드웨어 DRM이 아닙니다. 변경 가능한 Python 소스/변조된 EXE, 위조 PC 식별값, 아직 인증이 없는 구버전까지 완벽하게 막지 못합니다. 구버전은 이 서버만 올려도 갑자기 잠기지 않습니다. 기존 파일 회수까지 가능하다고 주장하지 마세요. 하나의 등록=한 PC/Windows 계정 조합 기준으로 관리하며 동일인의 여러 신청은 운영자가 판단합니다.
- 무료 사용량 한도 초과도 서버 장애처럼 영향을 줍니다. 운영 중 요청/DB 사용량을 확인하세요. 인증 서버를 자주 바꾸면 별도 등록이 필요합니다. 운영자 자신도 같은 서버에 신청·승인해야 합니다.

## 테스트 (실서비스/계정 불필요)

```powershell
node --test test_worker.mjs
```

Node 24의 로컬 SQLite로 신청→승인→중지→재신청 차단→재허용, 관리자 인증/CSRF/로그아웃/비밀번호 변경/요청 제한/초기화를 확인합니다. Cloudflare 실서비스의 D1/네트워크/지연 검증을 대체하지는 않습니다. 프로젝트 상위에서 `py -m unittest tests.test_online_access -v`로 앱 쪽 테스트도 실행합니다. 테스트에서 실제 승인 서버/OBS를 호출하지 않습니다.

공식 참고: [D1 시작](https://developers.cloudflare.com/d1/get-started/), [마이그레이션](https://developers.cloudflare.com/d1/reference/migrations/), [서버 비밀값 관리](https://developers.cloudflare.com/workers/configuration/secrets/).
